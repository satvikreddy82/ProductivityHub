# Productivity Hub

A modern React-based productivity application that combines task management and note-taking in one place.

Productivity Hub helps users organize their daily work by tracking tasks, marking them complete, and saving notes locally in the browser. The app is designed with a clean, dark productivity-focused interface and a responsive layout that works well on desktop and mobile devices.

## Features

### Task Management
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- View completed and pending task status
- Save tasks using localStorage

### Notes
- Create notes
- Edit notes
- Delete notes
- View all notes
- Save notes using localStorage

### UI/UX
- Responsive design
- Dark productivity-themed interface
- Purple and blue gradient theme
- Smooth animations
- Mobile-friendly layout
- Smooth navigation between sections

## Installation

Clone the repository:

```bash
git clone https://github.com/satvikreddy82/ProductivityHub.git
cd ProductivityHub
npm install
```

Run the app locally:

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal to view the app.
